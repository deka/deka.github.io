Ne pas générer de prompts trop abstraits ou trop froids pour les images de projet.

**Why:** Le premier prompt CMP était trop "brutalist" / géométrique pur, sans ancrage dans l'univers des systèmes logiciels et sans chaleur.

**How to apply:**
- Toujours utiliser l'ambre (#F5C36E) généreusement, pas seulement en ponctuation
- Ancrer la métaphore dans les systèmes logiciels (plans de service, flux de données, topologie) sans clichés (pas d'icônes, pas d'interfaces)
- Éviter les styles `brutalist`, `cold`, `high contrast monochrome`
- Préférer : `isometric software architecture diagram`, `artisan technical illustration`, `warm volumetric light`
